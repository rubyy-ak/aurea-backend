# Auréa

*Die Kunst, Düfte zu sammeln.*

[**Zur App →**](https://aurea-parfum.onrender.com)

</div>

---

Jeder Flakon erzählt eine Geschichte, doch je größer die Sammlung wird, desto schneller verliert man den Überblick.

**Auréa** ist eine Web-App für die eigene Parfümsammlung. Man legt seine Düfte mit ihren Noten an, bewertet sie, markiert Lieblinge und führt eine Wunschliste. Jeden Morgen schlägt Auréa einen Duft aus dem eigenen Regal vor, passend zum Wetter: leicht und frisch an warmen Tagen, warm und tief, wenn es draußen kalt ist.
